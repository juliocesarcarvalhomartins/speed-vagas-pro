# Frontend

Código-fonte real da interface do SPEED VAGAS 6.4.

- `index.html`: estrutura da interface
- `style.css`: estilos
- `app.js`: integração da interface com o backend
- `search_intelligence.js`: regras do Gestor Inteligente / Google + portais
- `live_jobs.json`: cache local de exemplo, vazio no repositório

O frontend não depende de arquivos decompilados.
